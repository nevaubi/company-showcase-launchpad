# Render services

- The IR deep build loop runs on the always-on Render worker `filedunder-ir-worker` (this folder's Dockerfile), with progress kept in the database so restarts resume. It reads companies one per lane (lanes and reader counts sized from the cgroup memory limit), holds a 3-minute lease tagged with its host so a restarted container takes over at once, never counts out-of-memory kills or blocked readers against a company, and readers wait out a replaced container's per-company hold (a company is finished only when every reader ran) — because fixed sizes and a long lease turned every crash into a 15-minute stall, and skipped readers marked companies done with files unread.
- Office engine: private repo `nevaubi/filedunder-office-engine`, Render service `filedunder-office-engine` (not shared with JuneDesk); it trusts only tokens from this app's `/api/public/office/jwks`.
- Office files: `office_files` rows (ULID ids, owner-only RLS) + private `office-files` bucket under `<uid>/`; engine tokens are minted only by `getEngineToken` (`src/lib/office/files.functions.ts`) with the `OFFICE_ENGINE_JWT_PRIVATE_KEY` secret, because the engine trusts nothing else.
- Writer saves the real `.docx` (built in the browser by `src/lib/office/writer-docx.ts`) plus a `<id>.writer.json` copy of the exact editor state; imported Word files are read with mammoth when no state copy exists yet.
- OfficeAI is the shared research agent (`runAgent`) plus per-editor tools from `src/lib/office/agent-tools.ts` (sent by `agentStep` when `office` is set) executed in the browser by each editor's executor (e.g. `writer-agent.ts`); add editor capabilities there, not a separate agent.
- Besides deep builds, the worker loop runs side jobs that need more than a scheduled call's few seconds: IR-website collection (`scripts/ir-site-daily.ts`, daily Firecrawl credit cap in job_state), one due report per 10 minutes (`scripts/reports-due.ts`) and the daily resumable label canon; each records its own pause in job_state instead of waiting for a person.
